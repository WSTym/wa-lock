# WhatsApp Web - Bloqueio Rápido 🔒

Extensão para o Google Chrome que fecha a conversa aberta e aciona o **Bloqueio do app** no [WhatsApp Web](https://web.whatsapp.com) com um único clique ou atalho de teclado.

---

## 🚀 Funcionalidades

1. **Ação Unificada em 1 Clique:**
   - Detecta e fecha a conversa aberta atual (*"Fechar conversa"* no menu do chat).
   - Imediatamente aciona o bloqueio nativo do WhatsApp (*"Bloqueio do app"* no menu principal).
2. **Botão Integrado ao WhatsApp:**
   - Adiciona um botão com ícone de cadeado 🔒 na barra superior do WhatsApp Web ao lado dos menus nativos.
3. **Atalho de Teclado Rápido:**
   - Pressione **`Alt + L`** a qualquer momento para fechar e bloquear instantaneamente.
4. **Popup no Navegador:**
   - Acesso rápido também pelo ícone da extensão na barra de ferramentas do Chrome.
5. **Modo Silencioso (Sem flickering):**
   - Executa a sequência de menus de forma transparente e imperceptível na tela.

---

## 📦 Como Instalar no Google Chrome

1. Abra o Google Chrome e acesse a página de extensões:
   ```
   chrome://extensions/
   ```
2. No canto superior direito, ative a chave **Modo do desenvolvedor** (*Developer mode*).
3. Clique no botão **Carregar sem compactação** (*Load unpacked*).
4. Selecione esta pasta do projeto:
   ```
   C:\Users\dev-sats\Desktop\lab\wa-lock
   ```
5. Pronto! A extensão estará instalada e ativa.

---

## ⚙️ Pré-requisito no WhatsApp Web

Para que o **Bloqueio do app** funcione, certifique-se de que o recurso de senha/bloqueio nativo do WhatsApp Web está configurado:

1. Acesse o [WhatsApp Web](https://web.whatsapp.com).
2. Clique no menu dos **3 pontinhos** no canto superior esquerdo > **Configurações**.
3. Vá em **Privacidade** > **Bloqueio de tela** (ou *Bloqueio do app*).
4. Marque a opção e defina a sua senha de desbloqueio.

---

## 🎯 Como Usar

- **Opção 1:** Clique no novo ícone de cadeado 🔒 na barra superior do WhatsApp Web.
- **Opção 2:** Pressione o atalho **`Alt + L`** em qualquer momento enquanto estiver no WhatsApp.
- **Opção 3:** Clique no ícone da extensão na barra de ferramentas do Chrome e selecione **Fechar & Bloquear Agora**.
